# UPshop Tauri v2 Auto-Updater & CI/CD Release Guide

This document provides complete instructions for generating signing keys, configuring GitHub repository secrets, and deploying over-the-air (OTA) updates for the UPshop desktop application.

---

## 1. Generating Cryptographic Signing Keys

Tauri v2 uses `ed25519` key pairs to cryptographically sign update binaries so users' computers can safely verify updates before installing.

Run the following command in your terminal:
```bash
npx tauri signer generate
```

You will be prompted to enter a password to protect your private key.

**Output Example:**
```text
Private key: dW50cnVzdGVkIGNvbW1lbnQ6IGF1dG9tYXRlZCBzZWNyZXQga2V5...
Public key:  dW50cnVzdGVkIGNvbW1lbnQ6IGF1dG9tYXRlZCBwbGFjZWhvbGRlc...
```

---
 
## 2. Configuring Public Key in `tauri.conf.json`

Open `src-tauri/tauri.conf.json` and insert your generated **Public Key**:

```json
"bundle": {
  "active": true,
  "createUpdaterArtifacts": true
},
"plugins": {
  "updater": {
    "pubkey": "YOUR_PUBLIC_KEY_STRING_HERE",
    "endpoints": [
      "https://github.com/YOUR_GITHUB_USERNAME/UPSHOP/releases/latest/download/latest.json"
    ]
  }
}
```

*Note: Replace `YOUR_GITHUB_USERNAME/UPSHOP` with your exact GitHub repository path.*

---

## 3. Configuring GitHub Repository Secrets

In your GitHub repository:
1. Go to **Settings** > **Secrets and variables** > **Actions**.
2. Click **New repository secret** and add:

| Secret Name | Description / Value |
|---|---|
| `TAURI_SIGNING_PRIVATE_KEY` | Paste the **Private Key** generated by `npx tauri signer generate` |
| `TAURI_KEY_PASSWORD` | Paste the password you entered when generating the key pair |
| `GITHUB_TOKEN` | Automatically supplied by GitHub Actions (no action required) |

---

## 4. Releasing a New Version (CI/CD Automated Flow)

Whenever you are ready to ship a new version (e.g. `v1.0.1` or `v2.0.0`):

### Step 4.1: Bump Version in Project Configs
Update `"version"` in:
- `package.json` -> `"version": "1.0.1"`
- `src-tauri/tauri.conf.json` -> `"version": "1.0.1"`
- `src-tauri/Cargo.toml` -> `version = "1.0.1"`

### Step 4.2: Commit & Push Version Tag
```bash
git add .
git commit -m "bump version to v1.0.1"
git tag v1.0.1
git push origin main --tags
```

---

## 5. What Happens Automatically on Release?

1. **GitHub Actions Workflow** (`.github/workflows/release.yml`) triggers on `v1.0.1` tag push.
2. Compiles production executables (`.exe` / `.msi`).
3. Signs binaries with your private key (`TAURI_SIGNING_PRIVATE_KEY`).
4. Generates `latest.json` updater manifest containing signatures and download links.
5. Publishes a new **GitHub Release** containing the signed installer and `latest.json`.
6. Installed desktop clients automatically detect the update, show a notification in the top header, download the update, and offer a 1-click **"Relaunch & Apply Update"** button.
