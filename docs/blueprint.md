# **App Name**: UPshop

## Core Features:

- Inventory Tracking: Comprehensive dashboard to monitor stock levels, item details, and pricing across the enterprise within a Windows desktop environment.
- Store Management & Stock Intake: Functional interface to transfer stock from central storage to the shop floor and collect new incoming stock, automatically incrementing active shop inventory via Python logic.
- Smart Notifications Hub: A dedicated notification system showing pending credit sales, progress tracker for outstanding balances, and automated alerts for decreasing product stock levels to trigger restocking.
- Sales Processing: Simplified point-of-sale interface for logging transactions and updating the stock database in real-time.
- SQLite Data Persistence: Robust local data management system using Python and SQLite for reliable storage of sales and inventory records on the local machine.
- Visual Analytics Dashboard: Main dashboard featuring frequently asked products, graphical representations of weekly cash sales versus days, and frequency charts for top-selling items.
- Returns Management System: Efficient module for managing product returns, including stock reinstatement and financial reconciliation logic.

## Style Guidelines:

- Primary color: Professional Navy (#1A237E) to instill trust and reliability.
- Accent color: Vibrant Amber (#FFC107) used for pending credit notifications and low-stock alerts.
- Primary font: 'Roboto' for its high readability in dense data tables and analytics dashboards on desktop screens.
- Linear, high-contrast icons to clearly distinguish between inventory, sales, dashboard, and notification tabs in the sidebar.
- Clean, sidebar-driven navigation optimized for Windows desktop aspect ratios, prioritizing the visibility of data visualizations and stock tables.
- Subtle slide-in transitions for notification panels and smooth scaling animations for dashboard charts.
